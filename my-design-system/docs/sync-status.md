## What each check means

- **Figma key:** The snapshot has the key needed to find the component and place it in another file.
- **Same name:** The Figma component is called what the code calls it (or the map says why not).
- **Same property names:** Every variant and boolean property in Figma is a prop in code.
- **Same options:** Every variant option in Figma is an allowed value in code.
- **Same defaults:** The default Figma variant uses the code defaults.
- **Code follows the rules:** No raw colours in the component code.
