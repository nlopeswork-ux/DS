{/* Example gallery in tabs — replaces several stacked <Canvas> blocks with a single navigable widget. */}
export const ExampleGallery = ({ tabs }) => {
  const [active, setActive] = useState(0);
  return (
    <div className="my-6 rounded-lg border border-secondary overflow-hidden">
      <div role="tablist" className="flex gap-1 border-b border-secondary bg-secondary px-2 pt-2">
        {tabs.map((tab, i) => (
          <button
            key={tab.label}
            type="button"
            role="tab"
            aria-selected={i === active}
            onClick={() => setActive(i)}
            className={cn(
              'rounded-t-md border border-b-0 border-transparent px-4 py-2 -mb-px text-sm font-semibold',
              i === active ? 'bg-primary text-primary border-secondary' : 'text-tertiary hover:text-secondary',
            )}
          >
            {tab.label}
          </button>
        ))}
      </div>
      <div className="relative isolate bg-primary p-6">{tabs[active].content}</div>
    </div>
  );
};

<h2 id="ux-guidelines" className="text-2xl font-semibold">UX Guidelines & When to Use</h2>

### When to use
- **Brand** — neutral product emphasis, e.g. a feature or onboarding step.
- **Gray** — neutral, low emphasis.
- **Info** — contextual information.
- **Success** — a completed operation.
- **Warning** — a risk or limitation.
- **Error** — a failure or a destructive action.

For a filled circle (Modal, Alert, Banner) use [Featured Icon](?path=/docs/components-misc-icons-featured-icon--docs).

<h2 id="anatomy-best-practices" className="text-2xl font-semibold">Anatomy & Best Practices</h2>

### Structure
- **Glyph** — any name from the `Icon` set, in the colour's foreground token. The default is `error`.
- **Inner ring** — 2px, 30% opacity, 4px outside the glyph.
- **Outer ring** — 2px, 10% opacity, 9px outside the glyph.

### Best practices
- The rings overflow the component's box: leave about 9px of room around it so they aren't clipped.
- The glyph is **always** a Material Symbol from the `Icon` set — never an ad-hoc SVG.

<h2 id="states" className="text-2xl font-semibold">States</h2>

Static and decorative — no interactive states. Hover, focus and disabled belong to whatever control contains it.

<h2 id="accessibility" className="text-2xl font-semibold">Accessibility (a11y)</h2>
- **Decorative:** the glyph is `aria-hidden` (the `Icon` default). Always pair it with visible text — never rely on color alone.
- **Contrast:** glyph and rings use the semantic foreground tokens, which adapt to dark mode.
