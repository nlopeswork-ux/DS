<h2 id="ux-guidelines" className="text-2xl font-semibold">UX Guidelines & When to Use</h2>

### ✅ When to use
- To represent a person (or, via the `company` status icon, an organization) anywhere in the UI — comment threads, member lists, navigation, the `Avatar + Label Group` combo.
- With `statusIcon="online-indicator"` for presence-aware contexts (chat, collaborative editing).
- With `statusIcon="verified"` to flag an authenticated/trusted account.

### 🚫 When not to use
- As a generic image thumbnail for non-person content — use a plain image or a dedicated media component.
- To convey more than one status at once — the overlay slot is single-select (`online-indicator` / `company` / `verified` / none).

### Content priority
When more than one content source is available, `Avatar` resolves in this order: **photo (`src`) → initials (`text`) → generic placeholder**. Set `placeholder` explicitly when you have neither a photo nor initials to fall back on cleanly.

<h2 id="anatomy-best-practices" className="text-2xl font-semibold">Anatomy & Best Practices</h2>

### Related pieces
- **`_Avatar online indicator`** — a small ring-bordered dot, green when online, gray when offline.
- **`_Avatar company icon`** — a square badge overlay for an organization; no dedicated Company/Org logo component exists yet, so a neutral placeholder glyph renders until it does (same approach as Badge's `flagSwap`/`avatarSwap` placeholders).
- **`_Verified badge`** — a solid blue circle with a white check, usable both as an Avatar overlay and standalone (its own size scale reaches up to 32px).
- **`_Avatar add button`** — a circular "+" button with Default/Hover/Focus/Disabled states and an "Add user" tooltip on hover, typically trailing an `Avatar Group`.
- **`_Avatar profile photo`** — a larger, square/portrait (not circular) framing for standalone profile shots, its own sm/md/lg scale (72/96/160px).

<h2 id="accessibility" className="text-2xl font-semibold">Accessibility (a11y)</h2>
- **Photos:** pass a meaningful `alt` (the person's name) whenever `src` is set — it defaults to an empty string (decorative) only because most Avatar instances sit right next to a visible name already (see `Avatar + Label Group`).
- **Status overlays:** `online-indicator`, `company` and `verified` are marked `aria-hidden`/decorative except `verified`, which carries `role="img"` + `aria-label="Verified"` since a checkmark alone isn't otherwise announced.
- **`_Avatar add button`:** a native `<button aria-label="Add user">`, reachable with `Tab` and activatable with `Enter`/`Space` — the tooltip is a supplementary visual hint, not the element's only accessible name.
