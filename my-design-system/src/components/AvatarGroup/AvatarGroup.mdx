<h2 id="usage" className="text-2xl font-semibold">Usage</h2>

Each avatar overlaps the previous one by 12px (`-ml-3`), with later avatars stacked on top and a white ring (the same `contrastBorder` every `Avatar` already has) doubling as the separator between them. Only `xs`/`sm`/`md` are supported — the overlapping-stack pattern is meant for compact summaries, not large hero-sized avatars.

<div className="relative isolate my-6 [&_.docs-story]:!py-4">
  <Canvas of={AvatarGroupStories.Sizes} withToolbar={false} sourceState="none" />
</div>

Pass `showAddButton` to trail the stack with an `_Avatar add button` (8px gap) — typically wired to open an "invite people" flow via `onAddClick`.

<h2 id="accessibility" className="text-2xl font-semibold">Accessibility (a11y)</h2>
- **Overflow counts:** when trimming a longer list down to the visible stack, surface the remaining count as visible text (e.g. a trailing `Badge` "+5") rather than only a color/visual cue.
- **Add button:** inherits `_Avatar add button`'s native `<button aria-label="Add user">` — reachable and operable by keyboard.
