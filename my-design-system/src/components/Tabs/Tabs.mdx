            {tab.label}
          </button>
        ))}
      </div>
      <div className="relative isolate bg-primary p-6">{tabs[active].content}</div>
    </div>
  );
};

# Tabs

Horizontal tabs switch between related views of the same content without leaving the page. Two types (**Underline** and **Button**) in two sizes, optionally full width. On mobile the tab list becomes a dropdown. For a stacked list beside the content use [Vertical Tabs](?path=/docs/components-vertical-tabs--docs).

<h2 id="ux-guidelines" className="text-2xl font-semibold">UX Guidelines & When to Use</h2>

### When to use
- Two to about eight peer sections of one context — account settings, a record's details, a dashboard's views.
- Content the user flips between often, where only one view matters at a time.

### Types
- **Underline** — a bottom rule; the current tab gets a 2px brand underline.
- **Button** — tabs sit in a bordered, tinted track; the current one is a white raised chip.

### When not to use
- Sequential steps (use a stepper) or navigation to different pages (use navigation links).
- A single section, or more tabs than fit — consider vertical tabs or a different structure.

<h2 id="anatomy-best-practices" className="text-2xl font-semibold">Anatomy & Best Practices</h2>

### Structure
- **Tab** — a label, plus an optional count badge (brand on the current / hovered tab, gray otherwise; always gray in Button).
- **List** — `gap-xs` between button tabs, `gap-lg` between underline tabs. The Underline list sits on a 1px `border-secondary` rule.
- **Sizes** — `sm`: 14px labels (36px button tabs, 32px underline). `md`: 16px labels (44px / 36px). In Button the track grows to `p-sm` and `rounded-xl` at `md`.
- **Full width** — tabs share the row equally (`fullWidth`).

### Best practices
- Keep labels short and parallel; put a count in the badge, not in the label.
- Keep the current tab in the URL or in state the parent owns (`value` + `onValueChange`) so a reload lands on the same tab.

<h2 id="accessibility" className="text-2xl font-semibold">Accessibility (a11y)</h2>
- **Semantics:** `role="tablist"` / `role="tab"` / `role="tabpanel"`, with `aria-selected`, `aria-controls` and `aria-labelledby` wiring each tab to its panel. Give the list an `aria-label`.
- **Keyboard:** only the current tab is in the Tab order (roving tabindex). ← → move between tabs — selection follows focus — and Home / End jump to the first / last tab.
- **Mobile:** below 640px the list is replaced by a dropdown (a combobox) with the same options.
- **Not only color:** the current tab also changes weight context via its fill, underline or line, not hue alone; the badge is plain text.
