<h2 id="usage" className="text-2xl font-semibold">Usage</h2>

Unlike `Badge` or `Social Icon`, `Country Icon` is not a variant-driven component set — it's a single component selected by a `code` string, following ISO 3166-1 alpha-2 (e.g. `"PT"`, `"US"`, `"BR"`). Two special values beyond the ISO list: `"GB-2"` (alternate UK flag — currently mapped to the same mark as `"GB"`, no visually distinct asset exists) and `"earth"` (a generic globe placeholder for "no specific country").

Flags are sourced from the vendored [`circle-flags`](https://github.com/HatScripts/circle-flags) SVG set (MIT-licensed, see `public/flags/LICENSE-circle-flags.md`) rather than hand-drawn — 234 accurate national flags is outside what can be reliably hand-vectored. This is the one component in the Design System that pulls in third-party vector assets instead of the local hand-drawn/Material Symbols convention (see `Social Icon` and `Icon`).

### Where it's used
- `Badge`'s `flagSwap` slot (`icon="Country"`).
- Anywhere a phone-number/country field, address form, or locale switcher needs a recognizable flag.

<h2 id="accessibility" className="text-2xl font-semibold">Accessibility (a11y)</h2>
- **Decorative by default:** rendered with an empty `alt=""` — a flag alone rarely carries meaning a screen reader user needs; pair it with a visible or `aria-label`led country name in the surrounding UI (e.g. a Dropdown option's text) rather than relying on the flag as the only cue.
- **Never color-only:** don't use a Country Icon as the sole way to distinguish otherwise-identical options — pair it with the country name.
