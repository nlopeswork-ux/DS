# Textarea

Multi-line text field for longer free-form content, sharing the same border/focus/destructive language as `Input`. 2 structural variants — Default and Tags (chip compose area).

<h2 id="ux-guidelines" className="text-2xl font-semibold">UX Guidelines & When to Use</h2>

### ✅ When to use
- To collect multi-line content — messages, descriptions, comments, feedback.
- With `type="tags"` when the user is composing a set of discrete keywords/labels rather than a paragraph.

### 🚫 When not to use
- For a single line of text — use `Input`, which is more compact and scans faster.
- For a fixed set of predefined options — use `Dropdown`.

<h2 id="anatomy-best-practices" className="text-2xl font-semibold">Anatomy & Best Practices</h2>

### Sizing
- The field has a single fixed size — 128px tall, 14px/12px padding — there's no `size` variant, unlike `Input`.
- `resizeHandle` (on by default) lets the user drag to grow the field beyond 128px; turn it off only when the surrounding layout can't tolerate a taller field.

### Label row
- `required` (asterisk) and `helpIcon` render in the **label row**, not inside the field itself — unlike `Input`, where the help icon sits inside the bordered container.

### Tags mode
- ✅ Enter turns the current compose text into a chip; Backspace on an empty compose line removes the last chip — mirrors the behavior of most email "To:" fields.
- 🚫 Don't mix Tags mode with long free-form paragraphs — if the content is prose, use the Default variant instead.

<h2 id="accessibility" className="text-2xl font-semibold">Accessibility (a11y)</h2>
- **Label association:** the label is linked via `htmlFor`/`id` (auto-generated with `useId` when no `id` is provided).
- **Error announcement:** `aria-invalid` and `aria-describedby` point to the error message so screen readers announce it as part of the field.
- **Chip removal:** every chip's remove button has an explicit `aria-label` ("Remove design-system") — never rely on the "×" glyph alone.
- **Visible focus:** the focus ring must never be disabled — it's the primary visual cue for keyboard navigation.
