<h2 id="ux-guidelines" className="text-2xl font-semibold">UX Guidelines & When to Use</h2>

### ✅ When to use
- For a filter/token list where each item can be removed (`action="X close"`) — search filters, multi-select input chips.
- For a selectable set of categories or facets, paired with `checkbox`.
- To show a labelled count next to a category (`action="Count"`) — e.g. unread items per folder.

### 🚫 When not to use
- As a static status/metadata indicator with no interaction — use `Badge` instead, which is built for that and offers a 12-color palette.
- For a single primary/secondary action — use `Button`.

<h2 id="anatomy-best-practices" className="text-2xl font-semibold">Anatomy & Best Practices</h2>

### Structure
- **Checkbox (`checkbox`)** — an optional leading selection control, always 16×16 regardless of `size`. Controlled via `checked`/`onCheckedChange`, or left uncontrolled with `defaultChecked`.
- **Icon (`icon`)** — `Dot` (small solid-color indicator), `Country` (`flagSwap`, defaults to a generic globe mark), `Avatar` (`avatarSwap`, defaults to a small placeholder), or none.
- **Label** — the Tag's text content (`children`).
- **Action (`action`)** — `Text only` (nothing), `X close` (dismiss button, fires `onClose`), or `Count` (a numeric badge, `count`).

### Best practices
- ✅ Use `Tag` inputs used in `Input`/`Textarea`'s `type="tags"` mode reuse this exact component — keep any custom tag chip elsewhere in the product consistent with it rather than re-implementing the look.
- ✅ Pair `checkbox` with a real controlled `checked` value in filter UIs, so the Tag's visual state always matches the underlying selection.
- 🚫 Don't combine `checkbox` with `action="X close"` in the same interaction model — pick one interaction per Tag (select vs. dismiss) to avoid ambiguous click targets.

<h2 id="accessibility" className="text-2xl font-semibold">Accessibility (a11y)</h2>
- **Checkbox:** rendered as a native `<input type="checkbox">`, reachable with `Tab` and toggled with `Space` — carries its own `aria-label="Select"`; wrap the Tag with a visible group label when the selection's meaning isn't already clear from the tag's own text.
- **`X close`:** rendered as a native `<button aria-label="Remove">`, reachable with `Tab` and activatable with `Enter`/`Space` — never a `<div onClick>`.
- **Decorative icons:** `Dot`, `Country` and `Avatar` slots are marked `aria-hidden` — the label text is the source of accessible meaning.
