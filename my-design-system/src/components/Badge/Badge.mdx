<h2 id="ux-guidelines" className="text-2xl font-semibold">UX Guidelines & When to Use</h2>

### ✅ When to use
- To surface a status at a glance — "Online", "Failed", "In review" — next to a record, row or card title.
- To label metadata that helps scanning — a category, a plan tier, a count.
- Inside a `Badge group` to pair a short highlighted value (e.g. "New") with descriptive text.

### 🚫 When not to use
- As a clickable action — a Badge carries no interaction of its own (aside from the optional `X close` dismiss slot). Use a `Button` or `Tag` when the element needs to be pressable or removable as a first-class action.
- For long or variable-length text — Badge is built for short, scannable labels (1-3 words), not sentences.
- To replace a form control — selecting one of several options is a `Radio`/`Dropdown` job, not a row of colored Badges.

### Choosing a color

The 12-color palette (`Gray`, `Brand`, `Error`, `Warning`, `Success`, `Blue light`, `Blue`, `Indigo`, `Purple`, `Pink`, `Orange`, `Gray blue`) is semantic first: prefer `Error`/`Warning`/`Success`/`Brand` for meaningful states, and reach for the extended hues (`Blue`, `Indigo`, `Purple`, `Pink`, `Orange`, `Gray blue`) only for non-semantic categorization (tags, teams, plan tiers) where an arbitrary but consistent color helps recognition.

<h2 id="anatomy-best-practices" className="text-2xl font-semibold">Anatomy & Best Practices</h2>

### Icon slots (`icon`)
- **`Dot`** — a small solid-color indicator, typically for live/online-style statuses.
- **`Country`** — a circular flag slot (`flagSwap`). Defaults to a generic globe mark ([Country Icon](?path=/docs/components-country-icon--docs)'s `"earth"` code) until a specific country is passed, e.g. `flagSwap={<CountryIcon code="PT" />}`.
- **`Avatar`** — a circular avatar slot (`avatarSwap`). Defaults to a small placeholder [Avatar](?path=/docs/components-avatar--docs) until a real photo/initials are passed, e.g. `avatarSwap={<Avatar size="xs" text="OR" />}`.
- **`Icon leading` / `Icon trailing`** — a generic icon slot (`iconLeadingSwap`/`iconTrailingSwap`) before or after the label.
- **`X close`** — a trailing dismiss button (`_Badge close X`); fires `onClose` when activated.
- **`Only`** — the badge renders just the icon, no label — always pair with an `aria-label` since the icon alone carries the meaning.

### Labels (badge text)
- ✅ Short, scannable — 1 to 3 words ("In review", "New", "Team A").
- 🚫 Don't write text in all caps — the Badge's color and border already communicate priority.
- 🚫 Avoid stacking more than one icon slot at once (e.g. `Dot` + `X close`) — the component renders a single icon slot at a time by design.

See every type/color/size/icon combination in the tab gallery under [UX Guidelines](#ux-guidelines).

<h2 id="accessibility" className="text-2xl font-semibold">Accessibility (a11y)</h2>
- **Contrast:** every color's fill/border/text combination meets WCAG AA (ratio ≥ 4.5:1) for text, through the `utility-{color}-50/200/700` token triplet.
- **Icon-only badges:** `icon="Only"` renders no label — always pass an explicit `aria-label` on the Badge so screen readers announce its meaning.
- **`X close`:** rendered as a native `<button aria-label="Remove">`, reachable with `Tab` and activatable with `Enter`/`Space` — never a `<div onClick>`.
- **Decorative icons:** `Dot`, `Country`, `Avatar`, `Icon leading`/`Icon trailing` slots are marked `aria-hidden` — the label text is the source of accessible meaning, the icon is a visual reinforcement only.
