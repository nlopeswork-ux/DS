<h2 id="ux-guidelines" className="text-2xl font-semibold">UX Guidelines & When to Use</h2>

### ✅ When to use
- Inside `Social Button` / `Social Button Group` (sign-in/connect flows).
- As a compact platform identifier in a list of connected accounts, integrations or share targets.

### 🚫 When not to use
- As a clickable control on its own — `Social Icon` is a presentational mark with no built-in interaction; wrap it in a `Button`/`Social Button` when it needs to be pressable.
- At any size other than 24×24 — the mark's internal proportions are tuned for that viewBox; scale the wrapping `<span>` rather than distorting the icon.

### Choosing a style
- **Brand** — the default, most recognizable choice; use on light/white surfaces where the platform's own colors read clearly.
- **Gray** — a neutral, low-emphasis alternative for dense lists (e.g. many connected accounts side by side) where 22 different brand colors would compete for attention.

<h2 id="anatomy-best-practices" className="text-2xl font-semibold">Anatomy & Best Practices</h2>

### Sourcing
- **Google, Facebook, Apple, X, Figma, Dribbble, LinkedIn, Slack** — hand-drawn local SVG marks (this project has no runtime icon-library dependency for brand logos, see CLAUDE.md); the first six are shared with `Social Button`. LinkedIn and Slack are hand-drawn because both were removed from the `simple-icons` library at their trademark holders' request.
- **The remaining 14 platforms** — official single-path marks extracted from `simple-icons` (MIT) at authoring time into a local, versioned data file (`simpleIconMarks.generated.ts`) — no runtime dependency on the package itself.
- **AngelList** — rendered via its modern rebrand mark, Wellfound (`simple-icons`' `siWellfound`), since AngelList itself no longer exists as a brand.

<h2 id="accessibility" className="text-2xl font-semibold">Accessibility (a11y)</h2>
- **Labeled by default:** the root `<span>` carries `role="img"` and `aria-label={platform}` — the mark alone (a colored shape) isn't self-describing to screen readers.
- **Not a control:** `Social Icon` renders no focusable element — pair it with a real `<button>`/`<a>` (e.g. `Social Button`) whenever the mark needs to be actionable, and let that element carry its own accessible name instead of relying on this one.
