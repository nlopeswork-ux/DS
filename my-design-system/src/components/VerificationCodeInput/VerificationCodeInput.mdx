# Verification Code Input

A row of large digit boxes for OTP/2FA codes, built on the `_Mega input field base` primitive. Auto-advances focus as the user types, supports Backspace/Arrow-key navigation, and splits a pasted code across every box. 3 sizes, 4 or 6 digits.

<h2 id="ux-guidelines" className="text-2xl font-semibold">UX Guidelines & When to Use</h2>

### ✅ When to use
- To collect a short, fixed-length numeric code sent by SMS, email or an authenticator app.
- When you want the browser's native one-time-code autofill to work — the first box sets `autoComplete="one-time-code"`.

### 🚫 When not to use
- For free-form or variable-length text — use `Input`.
- For codes that mix letters and numbers with no fixed pattern — a single `Input` with clear formatting guidance in the hint text is usually clearer than forcing letters into digit boxes.

<h2 id="anatomy-best-practices" className="text-2xl font-semibold">Anatomy & Best Practices</h2>

### Interaction
- ✅ Typing a digit auto-advances focus to the next box; `Backspace` on an empty box moves focus back and clears the previous digit.
- ✅ Pasting a full code into any box distributes it across the remaining boxes automatically.
- Use `onComplete` to trigger verification as soon as every box is filled — don't require a separate "Submit" click for a code this short.

### Digits
- Use `4` digits for SMS-style OTPs, `6` for TOTP/authenticator-app codes — match whatever length your backend actually issues.

<h2 id="accessibility" className="text-2xl font-semibold">Accessibility (a11y)</h2>
- **Grouping:** the boxes are wrapped in `role="group"` labelled by the visible label, so screen readers announce them as one field.
- **Per-box label:** each box carries its own `aria-label` ("Digit 2 of 6") since it's a separate native input.
- **Numeric keyboard:** `inputMode="numeric"` requests the numeric keyboard on mobile without changing the underlying `type="text"` (needed for single-character `maxLength` behavior across browsers).
- **Autofill:** the first box sets `autoComplete="one-time-code"`, so browsers/OS can offer to fill in an SMS-delivered code.
- **Error announcement:** `aria-describedby` on every box points to the error message when `error` is active.
